Legal AI Assistant is a web application that allows users to search Indian Penal Code (IPC) sections and view crime descriptions and punishments.  
The system provides fast search functionality, pagination for large datasets, and detailed explanations for each section.

---

## 🌐 Live Demo

https://legal-ai-assistant-muk0.onrender.com

---

## ✨ Features

- Search IPC Section by Number
- Search IPC Section by Crime Name
- View Detailed Section Explanation
- Pagination for Large Data
- Add New IPC Section
- Clean and Simple Interface
- Cloud Deployment
